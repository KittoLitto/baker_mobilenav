Reflection

Many of the things I was asked to do for this assignment were somewhat confusing to me. It seems I've still got a lot to learn about the sorts of things you're able to do with CSS as the exact mechanics of what makes the hamburger button open and close are still a little opaque to me. Being able to make it slide out like that is really cool though. Interesting that javascript is required to close it? I've also got to look more into accessibility features, I was aware of automatic screen resizing for mobile but never encountered all this aria stuff before.
